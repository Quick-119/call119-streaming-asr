# 119-call streaming ASR

Japanese emergency-call ASR research artifacts: model metadata, a comparison of the AI-teacher stage with a human-teacher follow-up stage, and a fully synthetic 30-call benchmark. The frozen model weights and all real emergency-call recordings and transcripts are excluded from this repository.

The [model guide](docs/model_access.md) explains which external artifacts are required to run inference. The [privacy policy for this repository](docs/privacy.md) describes what is deliberately excluded.
