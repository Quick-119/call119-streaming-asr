# `pseudo_quality_full`

自動文字起こしを教師にした段階の比較用チェックポイントです。Whisper large-v3のネイティブFP16重みを、AlignAttとVACを使用する0.5秒刻みのSimulStreamingで推論します。元の候補コーパス14,514通話から、自動文字起こし済みの12,232通話（100,801学習区間、498.23時間）を使用しました。初期値の`c37`アダプターには以前の人手データによる学習が含まれます。

容量の大きい`model/whisper.pt`は収録していません。必要なSHA-256は`6a6a1e65351d05384ed849dbd50258c95dfe10f2896598d6ab99e1359b03f685`です。[モデル利用ガイド](../../docs/model_access.md)に従い、**完全なfrozen bundle**を別途入手してください。ここにある設定は公開結果を確認するためのコピーで、これだけではモデルを実行できません。
