# 文字起こし後処理の検証

モデルの重みや推論パラメータを変えず、誤認識のうち文脈から判断できるものだけを [`runtime/postprocess.py`](../runtime/postprocess.py) で補正します。採用モデルのファイル推論例と `119-support` のライブ文字起こしで同じ規則を使います。

## 調査と採用基準

模擬119通報30件の正解・出力を通話ごとに照合し、誤りを数字表記、漢字表記、語句の誤認識、脱落、挿入に分けて確認しました。さらに、採用モデルの固定評価174件と重ならない、過去モデルの実通報評価329件を使って誤り候補を調べました。候補34件を個別に試し、採用した規則の組合せでも**各通話のCERが悪化しない**ことを確認しました。実通報の音声・正解文・出力文・通話IDはこのリポジトリに含めません。

規則は `起用歴`→`既往歴`、`建物の2体から`→`建物の2階から` のような限定的な置換です。句読点と空白は従来のCER正規化で除去します。`怪我`→`けが`、`痙攣`→`けいれん`、`子供`→`子ども` などの表記統一は模擬音声では改善しても実通報の正解表記と衝突したため、採用していません。`店員搬送`→`転院搬送` や `路列`→`呂律` も通話単位のCER悪化があり、採用していません。

## 検証結果

| 評価対象 | 通話数 | 補正前の誤り数 | 補正後の誤り数 | 悪化した通話 |
|---|---:|---:|---:|---:|
| 過去モデルの実通報評価、採用モデルの固定評価と非重複 | 329 | 54,958 | 54,936 | 0 |
| 採用モデル、模擬119通報 | 30 | 150 | 137 | 0 |
| 自動教師段階モデル、模擬119通報 | 30 | 185 | 172 | 0 |
| 通話学習なしモデル、模擬119通報 | 30 | 144 | 134 | 0 |

公開模擬音声の通話別結果は [`postprocess_comparison.json`](../benchmark/mock119_30/results/postprocess_comparison.json) にあります。実通報329件は別の過去モデルによる出力なので、この表の改善値を採用モデルの実通報での改善値として扱うことはできません。また、評価された音声以外での無悪化を保証するものではありません。

## 再評価

完全なモデルbundleで新しい模擬30件評価を実行した後、その保存結果を次のように後処理評価できます。後処理の前後で正解文、正規化、CER計算は同一です。

```bash
python benchmark/mock119_30/evaluate_postprocess.py \
  --input runs/mock119_30/my_model/result.json \
  --output runs/mock119_30/my_model/postprocess.json
```

ライブ表示は確定本文と部分本文を合わせた累積スナップショットを補正します。補正対象の語がその境界をまたぐ場合は、確定部分を遡って部分本文を書き換えず、語が確定する更新を待ちます。最終本文には全文で補正を適用します。
